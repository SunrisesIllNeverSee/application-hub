## Description

Y Combinator (YC) is a startup accelerator that provides seed funding, mentorship, and connections for early-stage startups. Twice a year it invests $500K in a large number of startups. The startups move to Silicon Valley for 3 months, and YC partners work intensively with them to get the company into the best shape possible before Demo Day.
