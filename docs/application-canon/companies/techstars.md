# Company Profile: Techstars

## Basics

- **Name:** Techstars
- **Type:** Accelerator (multi-program)
- **Domain:** founder

- **LinkedIn:** https://www.linkedin.com/company/techstars
- **Headquarters:** Boulder, CO
- **Founded:** 2006
- **Check size:** $20K for 6% equity (standard) + $100K convertible note (most programs)
- **Equity taken:** 6% (standard)
- **Program structure:** Multiple location/industry-specific programs per year, 13-week duration

## Description

Techstars is a worldwide network that helps entrepreneurs succeed. It runs 50+ accelerator programs per year across locations and industries, each lasting 13 weeks. Programs are mentor-driven — each startup gets matched with 10+ mentors. Techstars has funded 3,500+ companies with a combined market cap of $100B+.
