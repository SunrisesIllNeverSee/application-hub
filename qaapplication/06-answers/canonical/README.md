# Canonical Answer Layer

This directory contains the current, reusable answer variants for drafting.
It is deliberately separate from `../index/`, which is the append-only
provenance ledger of verbatim historical submissions.

## Contract

- Use a canonical answer as the starting point for new applications.
- Preserve historical submitted answers in `../index/`; do not rewrite them
  to match current positioning.
- Each factual claim must carry a source and an `as_of` date.
- If a fact changes (users, revenue, funding, product status), update the
  canonical variant before reusing it.
- Never treat an unverified figure as reusable application copy.

## Current investor narrative

**SigRank is the lead product and traction wedge.** MO§ES™ is the underlying
operator-measurement and governance infrastructure. Future drafts should start
with the live product, observed usage, and near-term commercial test; explain
the broader infrastructure only after establishing that concrete entry point.
